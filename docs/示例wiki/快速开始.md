# 快速开始

这是一个 **Markdown** 演示文档，用来验证以下能力：

- 样式化渲染（标题、表格、代码高亮、引用、列表）
- frontmatter 元信息（标题与标签会显示在页头）
- 静态资源关联（下面这张 SVG 图就是相对路径引用）

![示例图片](./assets/demo.svg)

## 表格

| 格式 | 展示方式 | 说明 |
|------|----------|------|
| `.md` | 服务端渲染 | 表格 / 代码高亮 / 图片 / 链接 |
| `.txt` | 等宽 pre | 自动识别 UTF-8 / GBK |
| `.html` | 原样返回 | 相对资源按上下文目录解析 |

## 代码高亮

```js
function greet(name) {
  console.log(`你好，${name}！`);
}
greet('Easy Wiki');
```
